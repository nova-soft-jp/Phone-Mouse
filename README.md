# Phone-Mouse

スマートフォンを、Windows PCのワイヤレスマウス・キーボードとして使うアプリです。  
PCに表示されるQRコードをスマートフォンで読み取ると、ブラウザーから操作できます。

## ダウンロード

### [Windows版 PhoneMouse.zip をダウンロード](https://github.com/nova-soft-jp/Phone-Mouse/raw/refs/heads/main/PhoneMouse.zip)

ダウンロードしたZIPを展開し、中の **PhoneMouse.exe** を起動してください。インストールは不要です。

## できること

- スマートフォンでPCのマウス操作、クリック、スクロール
- スマートフォンからPCへ文字を入力
- QRコードを使った簡単な接続
- ダーク／ライト表示の切り替え
- ウィンドウを閉じた後も通知領域に置いて接続を継続

## 使い方

1. PCとスマートフォンを同じWi-Fiに接続します。
2. ZIPを展開し、PCで **PhoneMouse.exe** を起動します。
3. スマートフォンのカメラでQRコードを読み取ります。
4. 表示されたURLを開くと、スマートフォンから操作できます。

## 接続を続ける・終了する

ウィンドウ右上の「×」を押すと、アプリは終了せず通知領域（タスクバー右下）に隠れます。接続を続けるときは、そのままで大丈夫です。再表示するときは通知領域のPhone-Mouseアイコンをクリックします。

完全に終了するときは、通知領域のPhone-Mouseアイコンを右クリックして「終了」を選びます。

QRコードを更新すると、前のQRコードでの接続は解除されます。スマートフォンで新しいQRコードを読み取ってください。同じQRコードを何度も読み取ると、スマートフォンのブラウザーにタブが増えることがあります。操作に使うタブは最後に接続したものです。

## 接続できないとき

- PCとスマートフォンが同じWi-Fiにつながっているか確認してください。
- QRコードを更新した場合は、新しいQRコードを読み取ってください。
- 以前開いた操作ページが残っている場合は、そのタブを閉じてから接続し直してください。
- Windowsのファイアウォールから通信の許可を求められた場合は、プライベートネットワークでの通信を許可してください。
