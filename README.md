# Phone-Mouse

スマートフォンを、Windows PCのワイヤレスマウス・キーボードとして使えるアプリです。

## ダウンロード

[PhoneMouse.exe をダウンロード](https://github.com/nova-soft-jp/Phone-Mouse/raw/refs/heads/main/PhoneMouse.exe)

## 使い方

1. 上のリンクから `PhoneMouse.exe` をダウンロードして起動します。
2. PCとスマートフォンを同じWi-Fiに接続します。
3. PCに表示されたQRコードをスマートフォンのカメラで読み取ります。
4. 表示されたリンクを開くと、スマートフォンを操作パッドとして使えます。

## 終了方法

ウィンドウ右上の「×」を押すと、アプリは終了せず通知領域（画面右下）に隠れます。接続を続けたいときはそのままで大丈夫です。

完全に終了するときは、画面右下のPhone-Mouseアイコンを右クリックして「終了」を選びます。

QRコードを更新すると、それまでの接続は解除されます。スマートフォンで新しいQRコードを読み取ってください。

## 接続できないとき

- PCとスマートフォンが同じWi-Fiに接続されているか確認してください。
- PC側で新しいQRコードを表示した場合は、そのQRコードを読み直してください。
